# Operator Guide

## First Deployment

1. Define learner consent and guardian contact rules.
2. Register one support program.
3. Add synthetic learners for dry run.
4. Run advisor in assisted mode.
5. Review progress reports with staff.

## Minimum Production Controls

- consent record
- role-based access
- guardian communication review
- data-retention policy
- escalation path for safeguarding concerns

## Certification

Certified operators must prove learner privacy, consent handling and human
review for high-stakes educational recommendations.
